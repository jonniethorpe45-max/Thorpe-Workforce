# Genesis Build Zero

Project Genesis lives in [`genesis/`](./genesis/).

This repository also contains Thorpe Workforce / Thorpe Desktop. Genesis Build Zero is co-located under `genesis/` so the Frontend/App Builder phase can proceed without replacing the existing product tree.

Quick start:

```bash
cd genesis
pip install -r requirements.txt
bash tools/start-dev.sh
```

See `genesis/README.md` and `genesis/RUNBOOK.md`.
