# ScoutAI

Stage 3 foundation lives in [`scoutai/`](./scoutai/) as an extractable standalone monorepo for `jonniethorpe45-max/ScoutAI`.

## Publish to the ScoutAI GitHub repository

The Cursor GitHub App currently has write access only to Thorpe-Workforce. After granting the app (or a personal `gh` login) write access to ScoutAI:

```bash
cd scoutai
bash scripts/publish-to-github.sh
```
