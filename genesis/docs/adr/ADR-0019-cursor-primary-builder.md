# ADR-0019: Cursor as Primary AI Builder

## Status

Accepted

## Context

Project Genesis needed a primary hands-on builder to convert Build Zero prototypes into production-shaped code.

## Decision

Select Cursor as the primary AI builder for the Frontend/App phase, with supporting builders for DevOps, Security, QA, and Documentation.

## Consequences

- Frontend migration is owned by Cursor agents operating in-repo.
- Handoffs must update backlog, ADRs, and next-builder prompts.
