## Nature of the invention

Jonathan is not a conventional support chatbot. It is a **local-first autonomous incident orchestration system** that:

- Plans repairs using rules and/or a structured LLM planner
- **Executes operating-system-level diagnostics and repairs on the client device before generating any user-facing AI narrative**
- Requires explicit user approval for mutating (system-changing) actions
- Verifies successful repairs with a follow-up health scan
- Operates core diagnostics **offline**, including a layered network connectivity suite
- Restricts autonomous tool execution via **cryptographically signed repair packs**
- Integrates **proactive background monitoring** (CPU, memory, disk) with handoff into the same repair pipeline

We believe the primary protectable concept is the **execute-then-narrate** architecture combined with signed tool allowlisting and offline diagnostic fusion.
