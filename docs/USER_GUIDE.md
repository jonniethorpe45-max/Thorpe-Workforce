# Thorpe User Guide

## Getting Started

1. **Install Thorpe** from the installer for your platform
2. **Launch** the application
3. **Meet Jonathan** — open **Jonathan AI** in the sidebar to start a conversation (the dashboard banner is a welcome message, not the chat)

## Running a System Scan

1. Navigate to **System Scanner**
2. Read the privacy notice and check **"I consent to system diagnostics"**
3. Click **Run System Scan**
4. Review your health score and detected issues
5. Click **Generate Diagnostic Report** to create a detailed report

## Talking to Jonathan

1. Go to **Jonathan AI**
2. Describe your issue in plain language
3. Choose beginner or advanced explanation level
4. Jonathan will ask follow-up questions and provide step-by-step guidance

**Tips:**
- Run a scan first for more accurate advice
- Jonathan never asks for passwords
- Enable cloud AI in Settings for enhanced responses

## Using Repair Center

> Requires Professional license

1. Go to **Repair Center**
2. Select a repair action
3. Review the purpose and risk level
4. Click **Execute Repair** to confirm
5. View results and check repair history

## Viewing Reports

1. Go to **Diagnostic Reports**
2. Select a report from the list
3. Review findings, recommendations, and plain-language explanation
4. Export as PDF (Professional license required)

## Knowledge Base

Browse articles by category or search for specific issues. Each article includes:

- Symptoms
- Causes
- Step-by-step fixes
- Prevention tips
- When to seek professional support

## Settings

- **Profile**: Set your name and skill level
- **AI**: Configure cloud AI (optional)
- **Privacy**: View data location and delete all data
